# BacAI - منصة تعليمية بالذكاء الاصطناعي 🎓

**BacAI** هي منصة ذكية مخصصة لمساعدة الطلاب من خلال توليد امتحانات وتصحيحها دلالياً باستخدام الذكاء الاصطناعي بناءً على بنك أسئلة يتم استخراجه تلقائياً من المناهج المرفوعة.

## الميزات الأساسية 🌟
- **توليد امتحانات تلقائية**: بناء اختبارات مخصصة بناءً على قوالب امتحانية وزارية.
- **استخراج أسئلة ذكي**: يقوم المشرف برفع الكتب والملخصات لتقوم المنصة باستخراج الأسئلة وإجاباتها وتخزينها في قاعدة البيانات عبر الذكاء الاصطناعي (Gemini).
- **التصحيح الدلالي (Semantic Grading)**: تصحيح أسئلة الطلاب المقالية بناءً على المعنى العلمي، وليس مجرد التطابق الحرفي، مع تقديم ملاحظات ذكية للطالب.
- **إدارة المواد الدراسية**: يمكن للمشرف إنشاء مواد جديدة ورفع ملفاتها بسهولة (تدعم أحجام ملفات ضخمة).
- **واجهة مستخدم احترافية**: مصممة بعناية لتناسب الطلاب وتقدم تجربة تفاعلية سلسة.

## التقنيات المستخدمة 🛠️
- **الواجهة الأمامية (Frontend)**: React, Vite, TailwindCSS, TypeScript.
- **الواجهة الخلفية (Backend)**: Node.js, Express, TypeScript, Prisma ORM.
- **قاعدة البيانات**: PostgreSQL (Supabase).
- **الذكاء الاصطناعي**: Google Gemini Pro (Text & Vision).

## طريقة التثبيت والتشغيل محلياً 💻

### 1. إعداد قاعدة البيانات والبيئة
قم بإنشاء قاعدة بيانات على Supabase واحصل على مفتاح API لخدمة Gemini.
ثم أنشئ ملف `.env` في مجلد `backend/` وأضف المتغيرات التالية:
```env
DATABASE_URL="postgresql://user:password@db.supabase.co:5432/postgres"
GEMINI_API_KEY="your-gemini-api-key"
JWT_SECRET="your-super-secret-key"
```

### 2. تشغيل الواجهة الخلفية
```bash
cd backend
npm install
npm exec prisma db push
npm run dev
```

### 3. إنشاء حساب المشرف
لتسجيل دخول المشرف لأول مرة، قم بتشغيل هذا الأمر من مجلد `backend`:
```bash
npx ts-node prisma/seed.ts "admin@email.com" "yourPassword" "اسمك"
```

### 4. تشغيل الواجهة الأمامية
في نافذة طرفية أخرى:
```bash
cd frontend
npm install
npm run dev
```

## النشر في بيئة الإنتاج (Deployment) 🚀
المنصة جاهزة للنشر المجاني:
- الواجهة الأمامية معدة للعمل على **Vercel** من خلال متغير البيئة `VITE_API_URL`.
- الواجهة الخلفية معدة للعمل على **Render** بشكل مباشر (Web Service).
